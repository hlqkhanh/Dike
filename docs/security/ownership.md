# Security ownership

| Area                            | Primary responsibility   | Backup responsibility    | Review cadence    |
| ------------------------------- | ------------------------ | ------------------------ | ----------------- |
| Repository access and rules     | Repository administrator | Second administrator     | Monthly           |
| Dependency and CodeQL alerts    | Backend/security owner   | Project maintainer       | Weekly            |
| Secret-scanning alerts          | Repository administrator | Backend/security owner   | Immediate         |
| Web privacy and client security | Web owner                | Backend/security owner   | Every relevant PR |
| Incident coordination           | Project maintainer       | Repository administrator | Per incident      |

Before pilot, replace role names with the three team members' GitHub handles and confirm that every member uses a separate account with 2FA.
